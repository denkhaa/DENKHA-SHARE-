DENKHA ID — WEBSITE TOP UP DEMO

FITUR
- Beranda premium dengan gambar yang diberikan.
- Pilih Mobile Legends: Bang Bang atau Free Fire.
- Katalog harga CONTOH (bukan harga resmi UniPin/Codashop).
- Input Player ID, Zone ID MLBB, nickname demo, jumlah paket.
- Validasi ID kosong, ringkasan pesanan, diskon simulasi 5%, dan total otomatis.
- Halaman QRIS DEMO (placeholder, bukan QR pembayaran valid).
- Status 6 langkah dan rincian transaksi berlabel SIMULASI SELESAI.
- Tombol WhatsApp admin contoh, nomor perlu diganti.

PENTING: Website ini prototipe UI. Tidak terhubung ke API game, payment gateway, atau layanan pengiriman top-up. Jangan menggunakannya sebagai bukti pembayaran atau layanan top-up sungguhan.

MENJALANKAN LOKAL
Ekstrak ZIP dan buka index.html. Jika gambar tidak tampil, pastikan folder assets ikut berada di samping index.html.

ONLINE GRATIS VIA GITHUB PAGES
1. Buat repository PUBLIC bernama denkha-website di https://github.com/new
2. Upload index.html ke root repository.
3. Buat folder assets dan upload hero.jpg, crown.jpg, logo.png, ice.jpg ke dalamnya.
4. Buka Settings > Pages.
5. Source: Deploy from a branch; Branch: main; Folder: /(root); Save.
6. Tunggu beberapa menit. URL berbentuk https://USERNAME.github.io/denkha-website/

WHATSAPP
Di index.html, cari const ADMIN_WA='6281234567890'; lalu ganti nomor contoh dengan nomor admin resmi dalam format internasional tanpa + atau spasi.
